# 传统文化画卷科普脚本

## 使用说明

- 全文共 5 幅画卷，每幅画卷固定 4 幕，字段名与顺序不可改动，供后续机械解析为前端 TypeScript 数据。
- 每幕固定三个字段：`画面` 是给前端的美术与镜头提示，不参与朗读；`故事` 是观众实际读到的旁白文案，80 至 150 字；`线索` 是交互钩子，约 20 字。
- **线索链必须完整**：第一至第三幕的线索各自指向下一幕，第四幕的线索指向本画卷的 `收尾知识点卡`，点击后弹出硬核知识条目。
- 画卷级固定字段：`主题`（不超过 12 字）、`总体画面风格`（一行美术方向）、`收尾知识点卡`（2 至 3 条，每条为"标题 → 一句话事实"）。
- 事实一律用保守措辞：传说加"相传""传说"，年代写"约""前后"，只写公认史实，不虚构引文与数据。

## 画卷 1 | 二十四节气
- **主题**: 一岁四时，节气流转
- **总体画面风格**: 水墨农耕长卷、暖土黄底色配青绿渐变

#### 第一幕 · 圭表测影
- **画面**: 土黄色旷野上，先民立起一根垂直木杆，正午日影投在地面的石尺上缓慢移动。镜头从影子的特写缓缓拉远，露出龟裂的田野与远处的炊烟，淡墨线勾出地平线。
- **故事**: 很久以前，人们靠天吃饭，却说不准什么时候播种、什么时候收割。有人在平地上立起一根木杆，天天记录它影子的长短。影子最长的那天是冬至，最短的那天是夏至。年复一年，这些标记连成了四季的刻度，看天，第一次变成了量天。
- **线索**: 影子定出了冬夏两至 → 中间还缺几格刻度？

#### 第二幕 · 黄河岸边的划分
- **画面**: 镜头沿黄河向东推移，河畔农人仰头看星，画面上叠出二十八宿的星图与整齐的田垄。土黄底色上浮起一圈淡青色的刻度环，一格一格慢慢补齐。
- **故事**: 商周时期，古人把天空分成二十八个区域，靠星象变化判断农时。到了战国前后，人们在冬至与夏至之间均匀切分，又加入立春、立夏、立秋、立冬四个大节，一年的骨架渐渐成形。黄河流域的物候，成了最早的一份时间表。
- **线索**: 二十四格初具雏形 → 谁把它正式定名"节气"？

#### 第三幕 · 太初历定名
- **画面**: 竹简在案上徐徐展开，西汉太初元年的历书悬在半空，二十四个名称依次亮起。镜头从竹简推向窗外，四季景物随名称快速更迭：桃花、蝉鸣、麦浪、雪原。
- **故事**: 西汉太初元年，官方历法把节气正式编入年历，每个节气都有响亮的名字：惊蛰、清明、小满、霜降。从这以后，上到朝廷颁布政令，下到农人安排农事，都照着这二十四个节点走。节气从观测记录，变成了人人可用的历法。
- **线索**: 历法定下了名字 → 它怎样走进百姓的餐桌与节日？

#### 第四幕 · 节气里的日子
- **画面**: 镜头绕行一圈回到今日乡村：清明踏青、冬至包饺子、大暑晒伏姜。画面分成四条横向长带，各占一季，镜头横移掠过，颜色由暖土黄渐入青绿、火红、靛蓝。
- **故事**: 今天，人们仍然跟着节气过日子：清明踏青扫墓，夏至吃面，冬至包饺子。北方有"白露早，寒露迟"的农谚，南方有"小满不满，干断田坎"的说法。节气没有停在课本里，它还藏在餐桌、天气和各地的方言当中。
- **线索**: 二十四节气至今仍在使用 → 打开收尾知识点卡

- **收尾知识点卡**:
  1. 世界非遗 → 2016年11月，二十四节气列入联合国教科文组织人类非物质文化遗产代表作名录。
  2. 节气怎么算 → 节气按太阳在黄道上的位置划分，每运行15度一个节气，一年360度正好24个。
  3. 冬至不是最冷 → 冬至这天太阳直射南回归线，北半球白昼最短，但最冷的日子通常在"三九"前后。

## 画卷 2 | 端午节
- **主题**: 汨罗江畔的端午记忆
- **总体画面风格**: 青绿水墨配朱砂点染，龙舟竞渡的横向长卷

#### 第一幕 · 江畔之人
- **画面**: 战国楚地的江岸上，薄雾青灰，屈原独立礁石回望都城。镜头从江面水纹上摇到他的背影，衣带被风扯动，远处城头的楚旗低垂，唯有一角朱红被风扬起。
- **故事**: 公元前278年前后，楚国郢都被秦军攻破。流放中的屈原悲痛难抑，写下《哀郢》《怀沙》。相传他在农历五月初五投汨罗江，以身殉国。这位诗人留下的《离骚》，到今天仍然被一遍遍诵读。
- **线索**: 诗人沉入江中 → 百姓为何争相划船而去？

#### 第二幕 · 划船与投食
- **画面**: 数十艘细长龙舟破浪并进，船头的龙头漆成朱红，桨手俯身齐划。镜头贴着水面横移跟拍，岸边人群抛出竹筒与饭团，江心激起一圈圈涟漪。
- **故事**: 江边百姓听说屈原投江，争相划船去寻他，这就是龙舟竞渡的来历。船没有找到人，大家又怕鱼虾啃食他的身体，就把米粮和鸡蛋投入江中。相传这便是粽子的前身。年年五月初五，江上鼓声不断。
- **线索**: 米粮散在江里太容易泡散 → 怎样才不散开？

#### 第三幕 · 药草与门户
- **画面**: 镜头从江面转进村巷，家家门楣插着艾草与菖蒲，孩童手腕系着五色丝线。俯拍视角下，屋檐、药囊、雄黄酒摆成规整的方形阵列，青绿色调里透出朱红。
- **故事**: 农历五月，湿热渐起，蚊虫滋生，古人称之为"恶月"。人们在门前挂艾草、菖蒲，随身佩香囊，还会饮一点雄黄酒，借草药的气味驱虫避疫。这些做法和纪念屈原并行不悖，端午从一开始就是两条线索交汇的节日。
- **线索**: 习俗与纪念并行 → 它何时成为正式节日？

#### 第四幕 · 从江边到世界
- **画面**: 镜头拉高俯瞰，同一时间轴上分层展开：唐代江上竞渡、明代市集角黍、今日国际龙舟赛。画面从青绿水墨逐渐过渡到明快的现代色，最后定格在一条冲过终点线的龙舟。
- **故事**: 到了唐代，端午已被视为大节，朝廷给假一天；角黍的包法在各地分化出甜咸两派。2009年，中国端午节入选联合国教科文组织人类非物质文化遗产代表作名录，成为我国首个入选的传统节日。今天，龙舟已经划向世界数十个国家。
- **线索**: 端午已是世界非遗 → 打开收尾知识点卡

- **收尾知识点卡**:
  1. 首个入选的节日 → 2009年9月，"中国端午节"列入联合国教科文组织人类非物质文化遗产代表作名录。
  2. 起源早于屈原 → 投江殉国是相传已久的说法，学界一般认为端午还吸收了夏季驱邪避疫的古俗。
  3. "端"就是"初" → 端午即初五，又称端阳、重午、龙舟节，五月第一个午日由此得名。

## 画卷 3 | 书法的演变
- **主题**: 一笔一画三千年
- **总体画面风格**: 素白宣纸底色，墨色由浓转淡，带金石拓片质感

#### 第一幕 · 龟甲兽骨
- **画面**: 殷墟灰褐色的土层中，一片龟甲被缓缓拾起，镜头推进甲面，刻痕在侧光下显出深深浅浅的沟壑。背景渐暗，只剩刻辞和火光跳动的暖橙。
- **故事**: 三千多年前，商代人占卜之前，会把要问的事刻在龟甲和兽骨上，再用火灼烧，看裂纹判断吉凶。这些刻出来的字就是甲骨文，目前已经认出大约1500个。汉字有实物可查的历史，就从这里开始。
- **线索**: 刻在骨头上的字太费劲 → 能不能写得快一点？

#### 第二幕 · 青铜与竹简
- **画面**: 镜头横移掠过成排的青铜鼎，铭文在幽绿的铜锈间若隐若现；随后切到案上铺开的竹简，扁方的笔画在简上一行行推进，笔尖饱蘸墨汁。
- **故事**: 商周时，文字被铸进青铜器，称为金文，笔画浑厚圆转。后来人们把字写在竹片和木片上，串成简册；写错了就用刀刮掉，"删"字的本义正是用刀刮简。到了秦汉，为了写得更快，字形开始变扁变方。
- **线索**: 字越写越扁 → 一种新的字体即将成型

#### 第三幕 · 蔡伦改进造纸
- **画面**: 造纸作坊里，树皮、麻头在水池中化为纸浆，竹帘抄起一层薄薄的纤维。镜头从贴上墙面的湿纸，切到王羲之《兰亭序》摹本的行书线条在纸上缓缓晕开。
- **故事**: 西汉已经有早期的纸，东汉蔡伦总结前人经验，改进了造纸术，用树皮、麻头、破布、旧渔网造出更好用也更便宜的纸。纸普及以后，书法摆脱了简牍的重量，行书和草书跟着兴起来。相传《兰亭序》写于一次暮春雅集，它的真迹早已不存。
- **线索**: 纸让书写自由了 → 字体怎样定下官方标准？

#### 第四幕 · 颜体与今日
- **画面**: 颜真卿《祭侄文稿》的涂改痕迹在镜头前放大，墨团与枯笔清晰可见；画面一转，少年在方格本上临帖，窗外是现代城市的天际线。镜头从拓片的黑白反相缓缓过渡到彩色。
- **故事**: 唐代的欧阳询、颜真卿、柳公权把楷书写到极致，后人称"颜筋柳骨"。颜真卿的《祭侄文稿》满纸涂改，被称为天下第二行书。今天，写字从课堂走到了屏幕上，但笔顺和结构仍然是识字教育的起点。
- **线索**: 从甲骨到屏幕 → 打开收尾知识点卡

- **收尾知识点卡**:
  1. 书体演变主线 → 甲骨文、金文、篆书、隶书、草书、楷书、行书，其中"隶变"是古文字转向今文字的分水岭。
  2. 蔡伦是改进不是发明 → 西汉已有灞桥纸一类早期纸张，蔡伦在东汉改进工艺，让纸得以大规模推广。
  3. 天下三大行书 → 王羲之《兰亭序》、颜真卿《祭侄文稿》、苏轼《寒食帖》并称三大行书。

## 画卷 4 | 丝绸之路
- **主题**: 驼铃串起的两千年
- **总体画面风格**: 大漠赭黄配西域靛蓝，敦煌壁画与商队剪影

#### 第一幕 · 出关
- **画面**: 晨光里，长安城门缓缓开启，一队骆驼鱼贯而出，镜头随着队尾的驼铃声摇向西边。黄土城墙在身后渐渐缩小，戈壁在前方铺开，画面主色是赭黄。
- **故事**: 公元前138年，汉武帝派张骞出使西域，本意是联络大月氏夹击匈奴。张骞被扣留十多年，最终辗转回到长安，军事盟约没有谈成，却带回了西域诸国的真实消息。后来他又走了一趟，这一行被史家称为"凿空"。
- **线索**: 张骞带回了消息 → 他还带回了什么新东西？

#### 第二幕 · 货物西去
- **画面**: 镜头沿沙漠中的商队横移，驼背上依次露出丝绸卷轴、漆器和铜镜；切到罗马贵族展开一匹轻薄的丝绸，光透过织物。两地画面用一条蜿蜒的沙丘线相接。
- **故事**: 中国的丝绸沿着这条路一路西行，走到罗马帝国的市场上，价钱一度贵过黄金。作为交换，葡萄、苜蓿、石榴、核桃进入中原，大宛的汗血宝马也来到了汉朝。东西两边并不知道对方的全貌，货物却先到了。
- **线索**: 丝绸换回了瓜果 → 谁把这些往来记了下来？

#### 第三幕 · 斑驳的洞窟
- **画面**: 敦煌莫高窟的外景先入画，镜头穿进洞窟，壁画上的飞天与胡旋舞者在火光里活动起来。石青、朱砂的矿彩在暗处发亮，镜头沿墙面缓缓横移，掠过牵驼的商旅形象。
- **故事**: 沿途的敦煌、吐鲁番留下了大量石窟和文书。壁画里有深目高鼻的胡商，也有中原样式的楼阁。这条路运的不只是货物，还有佛教、乐舞、天文和造纸术。唐代以后海上航路兴起，陆上通道的往来也没有断。
- **线索**: 壁画记下了往来 → 这条路今天还在吗？

#### 第四幕 · 从驼铃到列车
- **画面**: 镜头由壁画中的驼队渐变到今天的中欧班列，同一构图下，铁轨替代了沙丘。色调从赭黄转成钢青与亮橙，集装箱依次掠过镜头，最后拉远成一张横贯亚欧的路线图。
- **故事**: 2013年以后，"一带一路"让古老的通道重新繁忙，中欧班列把义乌的小商品运到马德里。沿线国家还共同申报了世界遗产，"丝绸之路：长安—天山廊道的路网"在2014年列入名录。驼铃换成了汽笛。
- **线索**: 丝路已是世界遗产 → 打开收尾知识点卡

- **收尾知识点卡**:
  1. 名字是近代才有 → "丝绸之路"由德国地理学家李希霍芬在1877年的《中国》一书中提出，古人并不这么叫。
  2. 不止是一条路 → 它是多条路线组成的交通网络，包括南道、北道，后来还加上海上航线。
  3. 交流是双向的 → 中国的丝绸和造纸术西传的同时，西方的葡萄、音乐、天文也进入了中国。

## 画卷 5 | 中国瓷器
- **主题**: 泥与火的千年窑变
- **总体画面风格**: 青白釉色配窑火橙红，器物特写与窑址俯瞰交替

#### 第一幕 · 一片原始瓷
- **画面**: 窑址探方中，考古者的手托起一片印纹硬陶残片，镜头推进断面，可见胎体上一层薄薄的青黄釉。背景是南方丘陵和龙窑长长的斜坡，晨雾还没有散。
- **故事**: 早在三千多年前的商代，我国南方已经烧出原始瓷，胎质和釉层还很粗糙，是瓷器的雏形，烧成温度已经超过1200摄氏度。先民在黏土、火候和釉料之间反复试错，这条路走了上千年。
- **线索**: 原始瓷还太粗糙 → 要怎样才能又薄又透？

#### 第二幕 · 千峰翠色
- **画面**: 越窑青瓷的莲瓣纹碗在转盘上缓缓旋转，釉面泛出湖水般的青绿；镜头一转，北方定窑的白瓷印花盘在冷光下呈现象牙白。两件器物并置，背景一暖一冷。
- **故事**: 东汉时期，浙江上虞一带烧出真正意义上的成熟青瓷，我国因此被称作"瓷器之国"。唐代形成"南青北白"的格局：越窑青瓷如玉，邢窑白瓷似雪。陆羽在《茶经》里品评诸窑，把越窑排在了前面。
- **线索**: 南青北白各有千秋 → 谁能把它们推上顶峰？

#### 第三幕 · 宋人与汝窑
- **画面**: 汝窑天青釉洗放在素案上，镜头极近距离掠过釉面细碎的开片纹，像冰裂一样蔓延。窗外是北宋汴京的市井，画面色调转成雨过天青的灰蓝，一行小字浮起又化开。
- **故事**: 宋代是制瓷的高峰，汝、官、哥、钧、定五大名窑各有绝活。汝窑烧造时间很短，传世器物只有数十件，釉色如雨后天青，开片细如冰裂。相传"雨过天晴云破处"那句话，说的正是这种颜色。
- **线索**: 宋人偏爱素雅 → 海上的船要把它们带去哪？

#### 第四幕 · 瓷路远航
- **画面**: 泉州港涨潮，满载瓷器的木船扬帆出海，镜头从甲板上的瓷堆升到桅杆顶端，再拉远成一条跨海航线。画面从灰蓝转为深靛与浪白，最后落在博物馆展柜中的一只元青花上。
- **故事**: 唐宋以后，瓷器改走海路外销，"南海一号"沉船上就装着成批的外销瓷。英语里的"china"既指中国，也指瓷器。元代青花成熟，明代郑和的船队带着瓷器七下西洋。一条海路，让世界记住了这种洁白坚硬的东西。
